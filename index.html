Privacy Policy

Shopee FB Autopost · Last updated: 9 November 2026 · ภาษาไทย

Shopee FB Autopost ("the App") is a private tool that publishes Shopee affiliate product posts to a Facebook Page managed by the App's operator. It runs on the operator's own computer and is not offered to the public.

Information the App uses

  • Facebook Page details: the Page ID, the Page name, and a Page Access Token for the operator's own Page.
  • Post content: the caption, product image URL, and affiliate link for each post, and the post ID returned by Facebook.
  • Shopee affiliate data: the operator's Shopee affiliate credentials and public product details such as name, price, image, and sales figures.

The App does not collect personal information about Facebook users. It does not read comments, private messages, follower lists, or profile data, and it does not use cookies or analytics.

How the information is used

The information is used only to verify the connection to the operator's Page, publish posts to that Page, and avoid posting the same product twice.

Storage and sharing

Configuration, the post queue, post history, and logs are stored only in local files on the operator's computer. The App does not sell or share this information. It sends data only to the Facebook Graph API and the Shopee Affiliate Open API, as needed to perform the functions above. Those services process data under their own privacy policies.

This page is hosted on GitHub Pages. GitHub may log technical data, such as IP addresses, when the page is visited.

Retention

Local data is kept until the operator deletes it. Posts published to Facebook remain on the Page until they are removed there.

Data deletion

To request deletion of any data related to you, email the contact address below with the subject "Data Deletion Request" and include the link to the relevant post or details of the data. Requests are processed within 30 days, and you will receive a confirmation by email.

You can also remove the App's access at any time in Facebook under Settings & privacy > Settings > Business integrations.

Changes

Any change to this policy will be published on this page with a new "Last updated" date.

Shopee FB Autopost ("แอป") เป็นเครื่องมือส่วนตัวสำหรับโพสต์สินค้า Shopee Affiliate ลงเพจ Facebook ที่ผู้ดูแลแอปเป็นผู้จัดการ แอปทำงานบนคอมพิวเตอร์ของผู้ดูแลเอง และไม่ได้เปิดให้บุคคลทั่วไปใช้งาน

ข้อมูลที่แอปใช้

  • ข้อมูลเพจ Facebook: Page ID ชื่อเพจ และ Page Access Token ของเพจผู้ดูแล
  • เนื้อหาโพสต์: แคปชัน ลิงก์รูปสินค้า ลิงก์ Affiliate และรหัสโพสต์ที่ Facebook ส่งกลับมา
  • ข้อมูล Shopee Affiliate: ข้อมูลยืนยันตัวตน Affiliate ของผู้ดูแล และข้อมูลสินค้าสาธารณะ เช่น ชื่อ ราคา รูป และยอดขาย

แอปไม่เก็บข้อมูลส่วนบุคคลของผู้ใช้ Facebook แอปไม่อ่านความคิดเห็น ข้อความส่วนตัว รายชื่อผู้ติดตาม หรือข้อมูลโปรไฟล์ และไม่ใช้คุกกี้หรือเครื่องมือวิเคราะห์สถิติ

วิธีใช้ข้อมูล

แอปใช้ข้อมูลเพื่อตรวจสอบการเชื่อมต่อกับเพจของผู้ดูแล โพสต์ลงเพจนั้น และป้องกันการโพสต์สินค้าซ้ำเท่านั้น

การจัดเก็บและการเปิดเผยข้อมูล

การตั้งค่า คิวโพสต์ ประวัติโพสต์ และบันทึกการทำงาน เก็บเป็นไฟล์บนคอมพิวเตอร์ของผู้ดูแลเท่านั้น แอปไม่ขายหรือแบ่งปันข้อมูลเหล่านี้ และส่งข้อมูลไปยัง Facebook Graph API และ Shopee Affiliate Open API เท่าที่จำเป็นต่อการทำงานข้างต้นเท่านั้น บริการทั้งสองประมวลผลข้อมูลตามนโยบายความเป็นส่วนตัวของตนเอง

หน้านี้โฮสต์บน GitHub Pages ซึ่งอาจบันทึกข้อมูลทางเทคนิค เช่น หมายเลข IP เมื่อมีผู้เข้าชม

ระยะเวลาการเก็บข้อมูล

ข้อมูลในเครื่องจะถูกเก็บไว้จนกว่าผู้ดูแลจะลบ โพสต์ที่เผยแพร่บน Facebook จะอยู่บนเพจจนกว่าจะถูกลบออกจากเพจ

หากต้องการขอลบข้อมูลที่เกี่ยวข้องกับคุณ กรุณาส่งอีเมลไปยังที่อยู่ติดต่อด้านล่าง โดยใช้หัวข้อ "Data Deletion Request" พร้อมแนบลิงก์โพสต์หรือรายละเอียดของข้อมูล คำขอจะได้รับการดำเนินการภายใน 30 วัน และคุณจะได้รับการยืนยันทางอีเมล
